# Level 5 Demo Walkthrough Script

Use this script to record a 4–6 minute screen walkthrough. Record on Stellar Testnet and blur or avoid any private information.

## 1. Introduce the product (0:00–0:35)

Open the landing page. Explain that Stellar Lending lets a Testnet user deposit native XLM as collateral and borrow dTOKEN in a non-custodial Soroban flow. Point out the 150% collateral ratio and the Testnet risk notice.

## 2. Show the guided first-use flow (0:35–1:15)

Open **Start on Testnet**. Show the Testnet safety note, Friendbot funding path, public-wallet proof requirement, and the three meaningful action choices.

## 3. Connect and deposit (1:15–2:20)

Connect Freighter on Stellar Testnet. Show the public address, Testnet balance, and Deposit page. Enter a small XLM amount, show the borrowing preview, then confirm the transaction.

## 4. Borrow and monitor health (2:20–3:25)

Open Borrow. Choose a safe amount within the displayed maximum, confirm the transaction, and return to Dashboard. Explain the collateral, debt, health factor, and USD value panels.

## 5. Repay or withdraw (3:25–4:20)

Open Repay and repay part or all of the dTOKEN debt. If using Withdraw instead, show that the interface prevents withdrawing collateral that would make the position unsafe.

## 6. Show risk management and proof (4:20–5:00)

Open Liquidate to show how unhealthy positions are handled. Then show the confirmed transaction in Stellar Expert, keeping the public wallet and hash visible as Testnet proof.

## Recording checklist

- Confirm the Freighter network is Stellar Testnet.
- Show at least one signed, confirmed transaction.
- Do not show a recovery phrase, secret key, or private account data.
- Include the live URL and repository URL in the description when publishing.
- Name the final video `stellar-lending-level5-demo` and add its public link to the README after publishing.
